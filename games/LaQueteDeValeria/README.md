# La Quête de Valéria

Dans le royaume de Valéria, le terrible dragon Ignirion a réduit en flammes le Château Eldrath et plongé le
peuple dans le désespoir. Tu devras traverser villages, forêts et ruines pour l'affronter. Tu es l'élu, le
seul à pouvoir libérer Valéria de son règne de feu.

- **Genre** : Aventure / quête
- **Auteurs** : Cassandra Brocail, Yanis Mas, Thomas Louradour
