# Score (démo interne)

Démo permettant de tester l'enregistrement d'un score via l'API `/api/scores`.

- **Genre** : Demo
- **Auteurs** : Benoit Darties
- **Visibilité** : ce jeu est marqué `"hidden": true` dans `game.json` et n'apparaît donc pas dans la liste des
  jeux de l'arcade. Il sert de référence pour brancher `static/js/score.js` dans un nouveau jeu.
